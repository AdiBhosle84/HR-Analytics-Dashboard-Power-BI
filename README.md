# 👨‍💼 HR Analytics Dashboard – Power BI

An interactive HR Analytics dashboard built using **Microsoft Power BI** to analyze employee attrition, workforce demographics, job satisfaction, salary distribution, and overall HR performance.

## 🚀 Project Overview

This dashboard provides actionable HR insights that help organizations understand employee retention patterns, department-wise attrition, and workforce distribution through interactive reports.

## ✨ Dashboard Features

* 👥 Total Employees KPI
* 📉 Employee Attrition Analysis
* 🏢 Department-wise Attrition
* 💰 Salary Distribution
* 🎓 Education Field Analysis
* 😊 Job Satisfaction Overview
* 👨‍💼 Age Group & Gender Distribution
* 📍 Interactive Filters and Slicers

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling
